Deepseek releases V4.1 Flash with standalone web retrieval APIs

Deepseek has released open weights for V4.1-Flash-1017 and opened programmatic access to its internal search infrastructure at 75 cents per 1,000 queries.

By Jonas Weber · Oct 17, 2026

Deepseek released V4.1-Flash-1017 as an open-weight model on Saturday, claiming faster task completion, lower per-task computational costs, and shorter overall output lengths compared to its immediate predecessor. The release targets agentic workflows that rely on rapid generation cycles.

Alongside the weights, the company introduced standalone Search and Fetch APIs designed to expose its internal web index to third-party developers for $0.75 per 1,000 calls. Deepseek is temporarily providing free API usage for developers connecting through tools such as Claude Code and Codex.
